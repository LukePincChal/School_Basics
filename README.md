# School_Basics
This is a simple program that eases and automates the problem solving calculus problems for polynomial continuous equations in which owns:

  **Function Plotter**
  -This function will be applied to a selected real x-value (so no complex nor vectorial inputs), in which the defined(created) function will return a defined value based on this same selected number.
  
  **Function derivator**
  -This function may be applied to a specific real x-value in which will return the exact slope of the define(created) function on that variable; or it may return the defined(created) function's derivate, being a pure function. 
  
  **Function Integrator**
  
  -This function may be applied to a specific real x-value in which will return the exact area value between two x-values; or it may return the defined(created) function's integral, being a pure function. 
  
  **Function Root finder**  
  
  -This function solves all the created(defined) function's roots with the application of a factor, in which facilitates the used method to find those roots; and the precision, in which helps the used method to approximate (if larger) and merge results faster(if samller).
  
  **Function Tangent Line**  
  
  -This function applies to a selected real x-value, returning a first-degree equation that is tangent to the equation at the exact selected x-value.
